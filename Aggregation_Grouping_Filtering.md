# SQL Practice Questions – Aggregation, Grouping & Filtering  
### (Flight Dataset)

These questions are based on the following SQL concepts shown in the images:

- COUNT, SUM, AVG, MIN, MAX  
- GROUP BY  
- ORDER BY with aggregates  
- HAVING clause  
- WHERE vs HAVING  

---

## Dataset Reference

Assume a table named **`flights`** with columns:

- flight_id  
- airline  
- source_city  
- destination_city  
- departure_year  
- ticket_price  
- aircraft_type  
- flight_duration
